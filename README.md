# 借势合力 · 原力创业 · 通关地图 · 绿皮书 · v1.0

> 给每一位站在第五康波深冬 × 第六康波初春交汇点的创始人 ——
>
> 这不是一本"AI 创业指南"，也不是一本"商业模式画布教科书"。
> 这是一本**通关地图**：用一个公式贯穿四个关口，把"创业"这件本来扑朔迷离的事，
> 收拢成一张可走的图。
>
> **一个公式：** 财富 = 借势 × 合力
> **四个关口：** 原力觉醒 → 品类独创 → 模式升维 → 壁垒锁定
> **一句话目标：** 左手现金流，右手资产雪球。
>
> 通完四关叫**出师**。出师才能拿到下一阶段的投资机会。

### 与 lean startup / YC / 个人英雄主义创业方法论的根本差异

| 传统创业方法论 | 借势合力 · 通关地图 |
|---|---|
| 从零造势 | **借势**：识别已有的康波周期之势（K1-K6 五次已发生 + 第六次初春） |
| 个人英雄主义（"找到你的痛点"） | **合力**：合天赋人格之力（12 原型 + 三圈交集） |
| 线性阶段（idea → MVP → PMF → Scale） | **四关严格递进**：觉醒 → 独创 → 升维 → 锁定，每关 5 项硬出师条件 |
| Pivot when broken | **品类独创**：从一开始就创造**无法分类**的新品类（十六字诀） |
| Hustle / grind | **借势 ≥ 努力**：势对力不对吃不到红利；力对势不对怀才不遇 |
| 1971 法币之后的方法论 | **AI 原生 + 第六康波春初**：技术势能与品类创新的共振时刻 |
| 商业模式发明 | **商业模式组合**：58 种商业基因 × 9 模块 × 3 链路（300 年验证过的基因片段） |
| 护城河 = 资本 / 网络效应 | **四维护城 16 控制点**：虚（心智）/ 实（物理）/ 入（锁定）/ 出（网络） |
| 心理账户 = 用户支付意愿 | **四大心理账户**：功能 / 情绪 / 社交 / 投资（神经科学 + 价格机制） |

### 时代锚点：千日窗口 2025-2028

我们正处在 **第五次康波（信息技术）深冬 × 第六次康波（AI / 生物科技 / 能源）初春** 的双周期叠加点。

康波理论提示：每次范式转移的最关键期是 **前 1000 天**。在这个窗口内建立的品类定义权和用户心智，会在后续 10-20 年内持续产生复利。

**2025-2028 = 第六次康波的千日窗口。错过了就要等下一个范式转移（约 50 年后）。**

这本绿皮书要让你不错过。

## 5. 通关规则（硬性）

**每关卷末有 5 项通关检查点**：

```
□ 第一关 原力觉醒 — 5 项
   1. 能 30 秒说清自己的三圈交集（非对称优势 × 非理性痴迷 × 非线性回报）
   2. 完成 12 原型测评，知道自己的原型与阴影
   3. 完成天才区能量回流测试，知道自己的天才区在哪一象限
   4. 完成 3-2-1 阴影练习，识别金色阴影
   5. 输出一句话原力定位（不超过 30 字）

□ 第二关 品类独创 — 5 项
   1. 用 16 字真言验证你的品类（4 维全部 ✓ 才算独创）
   2. 锁定甜用户：S 级客户 ≥ 5 + 4 维筛选全通过
   3. 30 秒电梯测试通过（5 个不同人都听懂 + 愿付钱）
   4. 找到至少 3 个"贵任务"用户痛点（落在情绪 / 社交 / 投资账户）
   5. 输出一句入脑价值主张（不超过 20 字）

□ 第三关 模式升维 — 5 项
   1. 完成商业模式 9 模块画布填满
   2. 9 张闭环验证测试卡至少 3 张跑通
   3. 三链路闭环跑通（获客 → 交付 → 变现一个真实订单）
   4. 找到至少 1 个 LTV/CAC > 3 的超级单点
   5. 用 ABCS 段位自评，达到 A 段位（有人真实付费）

□ 第四关 壁垒锁定 — 5 项
   1. 16 控制点至少 8 个达到"高分锚点"
   2. 至少 6 个控点在持续投资中
   3. 客户转换成本可量化（流失率 < 5%）
   4. 至少 1 个壁垒达到"竞品 6 个月追不上"标准
   5. 输出"我的护城河"一页纸（含证据 + 30 法则推演）
```

**不要跳关**。原力觉醒没完成不要做品类独创，品类独创没跑通不要做模式升维，模式升维没闭环不要做壁垒锁定。

**全部通关 = 出师 = 触发下一阶段投资机会 + 原力人生融合**。

### 概念地图使用说明

`dashboards/借势合力-原力创业-通关地图-v1.0.canvas` 是本书的**可视化通关索引**，符合 [JSON Canvas](https://jsoncanvas.org) 开放规范。

- **打开方式**：用 [Obsidian](https://obsidian.md) 把本仓库目录当作 vault 打开，双击 .canvas 文件
- **结构**：5 层 band 设计（总纲 / 借势 / 合力 / 四关 / 出师 + 总结），40 节点 / 10 条脊柱边
- **替代方案**：任何兼容 JSON Canvas 的编辑器（Foam / 自建渲染器）均可打开
- GitHub 直接预览会显示为 raw JSON（这是规范如此）
